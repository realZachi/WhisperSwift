# Changelog

All notable changes to WhisperSwift will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- SwiftLint configuration for code quality enforcement
- SwiftFormat configuration for consistent code formatting
- Pre-commit hooks for automated validation
- Dependabot for automated dependency updates
- GitHub Actions CI/CD workflows
- Issue and PR templates
- CODEOWNERS file for automatic review assignment
- Architecture documentation
- Runbooks for common operations
- Log scrubbing for sensitive data protection

### Changed

- Improved logging with sensitive data redaction

### Fixed

- None

## [1.0.0] - Initial Release

### Added

- Menu bar application with status indicator
- Global hotkey support (Fn, Option, Control)
- Hold-to-record and hands-free lock modes
- Groq API integration for transcription
- Automatic text insertion into focused application
- Manual paste fallback (Cmd+Ctrl+V)
- App-aware text formatting
- Settings window with API key configuration
- Microphone and Accessibility permission management
