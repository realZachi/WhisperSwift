# WhisperSwift Runbooks

This directory contains operational runbooks for common tasks and incident response.

## Available Runbooks

- [incident-response.md](./incident-response.md) - How to handle production issues
- [release-process.md](./release-process.md) - How to create a new release

## Using Runbooks

Each runbook follows a standard format:

1. **Overview** - What the runbook covers
2. **Prerequisites** - What you need before starting
3. **Steps** - Detailed step-by-step instructions
4. **Verification** - How to confirm success
5. **Rollback** - How to undo if needed
6. **Contacts** - Who to reach out to for help
